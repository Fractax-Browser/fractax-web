# fractax.com

Web pública de [Fractax](https://fractax.com) (GitHub Pages) y descargas de la app (GitHub Releases).

- HTML y CSS estáticos, sin dependencias ni cookies. Español en `/` e inglés en `/en/`.
- Enlaces de descarga y de pago en un solo sitio: `site.js` (`FRACTAX_LINKS`).
- Las páginas legales son borradores: revisar y completar los datos entre corchetes antes de publicar.

Vista previa local: `python3 -m http.server 8765` y abrir http://127.0.0.1:8765/
